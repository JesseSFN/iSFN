    Nieuwe vraag

    Klik op de kaart of sleep de marker om de plek te kiezen. Een straal van 0,2 is 200 meter.

    Publiceren slaat de vragen op de server op: spelers zien ze zodra ze de pagina verversen. Bij elke keer publiceren wordt eerst een back-up van de vorige versie bewaard.

    Hoe publiceer ik dit?
    1. Klik op Download locations.js.
    2. Vervang game/locations.js in de repository door dat bestand en commit het.
    3. Heb je media toegevoegd? Zet dat bestand ook in media-vragen/.

    Je concept wordt alleen in deze browser bewaard. De spelers zien pas iets nieuws na stap 2.
